# 백준 10815 숫자 카드

## 문제 설명

상근이는 숫자 카드 N개를 가지고 있습니다. 각각의 카드에는 정수가 하나 적혀있습니다.
다음으로 M개의 정수에 대해 각 숫자가 상근이가 보유한 카드에 존재하는지 확인하려고 합니다.
각 숫자에 대해 존재하면 1, 존재하지 않으면 0을 출력합니다.

## 해결 방법

- 카드 번호들을 `Set`에 저장하여 O(1)에 가까운 탐색 속도를 얻습니다.
- 확인하고자 하는 숫자를 순회하며 `Set.has()`로 존재 여부를 체크합니다.
- 결과는 공백으로 구분된 문자열로 반환합니다.

## 실행 방법

```bash
npx ts-node index.ts < input.txt
```

또는 아래와 같이 컴파일 후 실행할 수도 있습니다.

```bash
npx tsc index.ts && node index.js < input.txt
```

온라인 저지에서는 표준 입력을 그대로 사용하면 됩니다.

## 테스트 방법

`vitest`를 사용하여 테스트를 실행할 수 있습니다.

```bash
npx -y vitest run index.test.ts
```
